# TEST-codeeditor

一个轻量级的代码编辑器项目。

## 简介

TEST-codeeditor 是一个用于测试与演示的代码编辑器，提供简洁的编辑体验，方便快速编写、修改和管理代码文件。

## 功能特性

- 📝 简洁直观的代码编辑界面
- 📂 文件与文件夹的创建、重命名、删除
- 🔍 项目内文本搜索
- 🌿 内置 Git 支持（提交、推送、分支管理）
- 🤖 集成 HippoxOS 代码编辑助手

## 快速开始

1. 克隆本仓库：

   ```bash
   git clone <repository-url>
   cd TEST-codeeditor
   ```

2. 打开项目文件夹即可开始编辑。
